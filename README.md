Entry for the [make.fun bounty "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

`main.ts` (Node 22) writes one short text to `/output/entry.txt` — 276 Unicode
code points, deterministic, no network. The text speaks to the judge reading
it: a thousand small texts tonight, each asking to be chosen; this one asks
nothing — only a letter that has waited forty years in a drawer, sealed, in
a hand the reader almost knows, in a house with its lights still on. The
reader will never know what it says, and is still wondering.

## Run

```sh
node main.ts   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
